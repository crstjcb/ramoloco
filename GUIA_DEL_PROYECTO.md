# Ramo Loco — estructura del sitio

## Páginas
- `index.html` — Inicio y arreglos destacados.
- `catalogo.html` — Catálogo interactivo y productos.
- `carrito.html` — Carrito y confirmación del pedido.
- `envios.html` — Información de entregas.
- `nosotros.html` — Historia y presentación de la floristería.
- `contacto.html` — Formulario de contacto.

## Archivos compartidos
- `css/styles.css` — Diseño, colores, componentes y animaciones.
- `js/main.js` — Funciones del menú, carrito, ubicaciones y catálogo.
- `logo-ramo-loco.png` — Identidad gráfica.

## Cómo probarlo
Abre `index.html` en un navegador o usa Live Server en Visual Studio Code.
Conserva las rutas relativas y la estructura de carpetas.

## Antes de publicar
- El carrito usa almacenamiento local del navegador.
- La confirmación de pedidos no los envía a un servidor.
- El formulario de contacto prepara/copia un mensaje, pero **no envía WhatsApp automáticamente**.
- El acceso a Recurrente no es una integración de cobro real.
- Para pagos y pedidos reales se requiere integración con servicios seguros.
